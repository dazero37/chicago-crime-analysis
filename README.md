# 🕵️ 시카고 범죄 데이터 분석
## 도시 범죄 패턴 분석을 통한 예방 전략 수립 <br>
멋쟁이사자처럼 데이터 분석 4기 파이널 프로젝트 2팀

> 이 프로젝트는 시카고에서 2001년부터 2017년까지 발생한 범죄 데이터를 바탕으로  
> 시간대, 지역, 범죄 유형 간의 연관성을 분석하고  
> 효과적인 범죄 예방 및 자원 배분 전략 수립을 위한 인사이트를 도출하였습니다.



## 📦 데이터셋 출처
- 출처: https://www.kaggle.com/datasets/abhisheksinghblr/chicago-crime
- 기간: **2001.01 ~ 2017.01**
- 데이터 포맷: CSV



## 🧾 프로젝트 기록 (노션)
> https://raspy-breadfruit-944.notion.site/2-Final-project-1c03f8e7ac0e8085ada6ffb343e45636



## 💡 문제 정의
> 범죄 발생 패턴을 분석하여 시간대별, 지역별, 범죄 유형별 특성 파악
> 효율적인 치안 자원 배분으로 시민 안전 증진 및 행정 효율성 향상



## 🎯 프로젝트 목적
> 범죄는 시민의 삶의 질과 직결되는 핵심 사회 문제
> 데이터 기반 분석을 통해 자원 배분의 효율성 향상
> 경찰 순찰 및 감시 인프라의 최적화된 운영 전략 제시



## 🔧 데이터 전처리
- 다량의 결측치 채우기
- 시카고 경계를 벗어난 데이터 제거
- 커뮤니티 지역 0.0(경계에 위치) 제거


## 📍 분석
- 카테고리별 (장소, 시간, 가정 폭력, 평균 소득) 분석
- 각 변수와 범죄 유형과의 연관성 파악 (카이 제곱 검정)
- 표준화 잔차로 2차 검증


## 🤖 머신러닝 모델링

### 🎯 목표
- **범죄 유형 예측 모델** 

### 🧠 사용 모델 및 성능

| 모델       | Accuracy | Macro F1 |
|------------|----------|----------|
| XGBoost    | 45.96%   | 0.23     |
| CatBoost   | 46.00%   | 0.21     |
| LightGBM   | 36.89%   | 0.12     |
| AdaBoost   | 35.00%   | 0.05     |


- **XGBoost가 가장 우수한 성능을 보임**
- CatBoost는 불균형 문제를 겪고 있는 것으로 판단
- AdaBoost, LightGBM 등은 클래스 불균형에 취약



## 🔍 결론 및 인사이트
- **시간대**, **장소**, **구역 정보**는 범죄 예측 및 대응 전략 수립에 핵심적
- **XGBoost 모델**은 범죄 유형 예측에 가장 적합
- **통계 분석**과 머신러닝을 병행하여 근거 기반 인사이트 확보
- 향후에는 실시간 모니터링 시스템이나 범죄 위험 시각화 대시보드로 확장 가능


## 개선점
- target값을 범죄 유형이 아닌 범죄 여부로 잡았으면 더 높은 정확도가 나옴.
- 세션 다운 문제 : Early Stopping 적용
- 모델 간 성능 편차 : 앙상블 기법 활용 가능성 검토, 모델별 전처리 전략 차별화
