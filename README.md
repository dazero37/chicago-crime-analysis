# 🕵️ 시카고 범죄 데이터 분석
## 도시 범죄 패턴 분석을 통한 예방 전략 수립 <br>
멋쟁이사자처럼 데이터 분석 4기 파이널 프로젝트 2팀


## 📌 프로젝트 개요
> 이 프로젝트는 시카고에서 2001년부터 2017년까지 발생한 범죄 데이터를 바탕으로  
> 시간대, 지역, 범죄 유형 간의 연관성을 분석하고  
> 효과적인 범죄 예방 및 자원 배분 전략 수립을 위한 인사이트를 도출하였습니다.

---

## 🎯 프로젝트 목적
- 범죄는 시민의 삶의 질과 직결되는 핵심 사회  문제
- 데이터 기반 분석을 통해 자원 배분의 효율성 향상
- 경찰 순찰 및 감시 인프라의 최적화된 운영 전략 제시

## 📊 주요 분석 결과

### 📍 발생 위치 분석
- 범죄 발생 상위 장소: 거리 > 주거지 > 인도 > 아파트
- 체포율 상위 장소:
  - 공공주택 부지 (70.3%)
  - 대형 백화점 (59.3%)
  - 식료품점 (55.3%)

### ⏰ 시간대별 패턴
- 주중 점심시간(12~13시), 금요일 저녁~심야(18~24시) 범죄 집중
- 연도별로는 금융위기 등 경기침체 시기 범죄 증가
- 카이제곱 검정 결과:
  - 시간대, 월, 연도와 범죄 유형 간 통계적 유의성 확보
  - 시간대: 약한 관련성 (Cramér’s V = 0.13)

### 🗺️ 지역 분석
- Ward, District, Community Area별 범죄 분포 시각화
- 지역별 특성에 따라 특정 범죄 유형 집중
- 통계적 관련성: District > Ward > Community 순

### 💰 소득과 범죄
- 평균소득과 범죄 유형 간 분포 시각화
- 소득 수준 낮은 지역에서 절도 및 폭력 유형 비중 상대적으로 높음

## 🤖 머신러닝 모델링

### 🎯 목표
- **범죄 유형 예측 모델** 구축 (분류)

### 🧠 사용 모델 및 성능

| 모델       | Accuracy | Macro F1 |
|------------|----------|----------|
| XGBoost    | 45.96%   | 0.23     |
| CatBoost   | 46.00%   | 0.21     |
| LightGBM   | 36.89%   | 0.12     |
| AdaBoost   | 35.00%   | 0.05     |

- **XGBoost가 가장 우수한 성능을 보임**
- AdaBoost, LightGBM 등은 클래스 불균형에 취약

### 🛠 개선 방안
- 오버샘플링 (예: SMOTE)
- 클래스 가중치 조정 (`class_weight='balanced'`)
- 다중분류 → 이진분류로 재정의 가능성 고려
- 조기 종료 (EarlyStopping), 하이퍼파라미터 튜닝 도입
- 차원 축소 기법 적용 고려 (PCA, LDA 등)
